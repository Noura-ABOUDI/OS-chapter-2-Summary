1. L’idée de base : un restaurant

Un ordinateur fonctionne comme un restaurant. Vous n’entrez jamais en cuisine : vous passez commande et quelqu’un vous apporte le résultat. Appuyez sur le bouton pour suivre une commande jusqu’en bas, puis son retour.

À retenir : chaque couche ne parle qu’à sa voisine. Les programmes ne touchent jamais le matériel directement : le noyau le protège.

2. D’où vient Linux ?

Faites défiler horizontalement. Chaque étape ajoute une pièce du puzzle.

🏢1969UNIX est créé aux Bell Labs par Ken Thompson et Dennis Ritchie.
🎁1983GNU : Richard Stallman lance un système de type UNIX entièrement libre.
🧩1991Noyau Linux : l’étudiant Linus Torvalds partage la pièce manquante.
🌀1993Debian : l’une des premières distributions.
🟠2004Ubuntu amène Linux sur les ordinateurs de tous les jours.
📱2008Android : le premier téléphone basé sur le noyau Linux.

GNU : la boîte à outils libre

GNU signifie « GNU’s Not Unix » (« GNU n’est pas Unix »). Le nom se contient lui-même : c’est une blague de programmeurs appelée acronyme récursif. Richard Stallman l’a lancé en 1983 pour que chacun puisse exécuter, étudier, modifier et partager les logiciels.

GNU

⚙️ Noyau Linux

Linus Torvalds, 1991

Le moteur. Il gère le processeur, la mémoire, les périphériques et les fichiers. Il n’a ni shell, ni commandes, ni applications.

🛠️ GNU

Richard Stallman, 1983

Les outils autour du moteur : Bash, GCC, glibc, et des commandes comme ls, cp et cat.

Linux est-il un noyau ou un système d’exploitation ?

⚙️🛞🎛️💺🚗
Un moteur seul ne peut aller nulle part. C’est le noyau Linux seul.
Réponse : à proprement parler, Linux n’est que le noyau. Un système d’exploitation complet est GNU/Linux (noyau + outils GNU). Dans la vie courante, on dit « Linux » pour tout le système, comme Ubuntu ou Debian, mais la partie qui s’appelle vraiment Linux est le noyau.

Open source signifie que tout le monde peut lire, modifier et partager le code, et même créer sa propre version de Linux.

4. Les distributions : même noyau, emballage différent

Une distribution = noyau Linux + outils GNU + gestionnaire de paquets + bureau et applications, assemblés pour un usage précis. Pensez au même moteur dans différentes voitures.

5. Terminal, shell, CLI, GUI

Quatre mots que les étudiants confondent souvent.

CLI : taper des commandes

🪟 Terminal (la fenêtre)
$ ls Documents
🐚 Shell (Bash, Zsh, Fish) : le programme dans la fenêtre. Il lit votre commande et la transmet au noyau.

GUI : cliquer et glisser

📁🌐📝🎵🖼️⚙️🗑️📧🖱️

Fenêtres, icônes et souris. Exemples : GNOME, KDE.

Le trajet d’une commande : Vous → Terminal → Shell → Noyau

La CLI est rapide et automatisable : serveurs et DevOps l’utilisent. La GUI est plus facile à apprendre.
