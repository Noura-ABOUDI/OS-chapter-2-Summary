1. The big idea: a restaurant

A computer works like a restaurant. You never walk into the kitchen. You order, and someone brings the result. Press the button to follow one order all the way down, then back up.

USER SPACE (where programs live)
🧑‍🍳
You, the customerYou write a program or type a command
🛎️
WaiterShell and applications: take your order
📖
MenuSystem libraries (glibc): ready-made functions like printf()
KERNEL SPACE (protected area)
🪟
Order windowSystem call interface: the only door to the kernel, e.g. write()
👨‍🍳
Head chefLinux kernel: manages processes, memory, devices, files, security
🔥
Stove and fridgeHardware: CPU, RAM, disk, screen
Press “Run” to start.

Remember: each layer talks only to its neighbour. Programs never touch the hardware directly. The kernel protects it.

2. Where did Linux come from?

Scroll sideways. Each step adds one piece of the puzzle.

🏢1969UNIX is created at Bell Labs by Ken Thompson and Dennis Ritchie.
🎁1983GNU: Richard Stallman starts a completely free UNIX-like system.
🧩1991Linux kernel: student Linus Torvalds shares the missing piece.
🌀1993Debian: one of the first distributions.
🟠2004Ubuntu brings Linux to everyday desktops.

GNU: the free toolbox

GNU stands for “GNU’s Not Unix”. The name contains itself, which is a programmers’ joke called a recursive acronym. Richard Stallman started it in 1983 so that anyone could run, study, modify and share the software.

GNU

⚙️ Linux kernel

Linus Torvalds, 1991

The engine. It manages the CPU, memory, devices and files. It has no shell, no commands and no apps.

🛠️ GNU

Richard Stallman, 1983

The tools around the engine: Bash, GCC, glibc, and commands like ls, cp and cat.

Is Linux a kernel or an operating system?

⚙️🛞🎛️💺🚗
An engine alone cannot take you anywhere. That is the Linux kernel alone.
Answer: strictly speaking, Linux is only the kernel. A complete operating system is GNU/Linux (kernel + GNU tools). In daily life people say “Linux” for the whole system, such as Ubuntu or Debian, but the kernel is the part that is really called Linux.

Open source means anyone can read, change and share the code, and even build their own Linux.

5. Terminal, shell, CLI, GUI

Four words that students often mix up.

CLI: type commands

🪟 Terminal (the window)
$ ls Documents
🐚 Shell (Bash, Zsh, Fish): the program inside the window. It reads your command and passes it to the kernel.

GUI: click and drag

📁🌐📝🎵🖼️⚙️🗑️📧🖱️

Windows, icons and a mouse. Examples: GNOME, KDE.

The path of a command: You → Terminal → Shell → Kernel

CLI is fast and can be automated, so servers and DevOps use it. GUI is easier to learn.

Who started the GNU project, and when?

Richard Stallman, in 1983.

Linux vs GNU/Linux?

Linux is only the kernel. GNU/Linux is the kernel plus the GNU tools: a complete OS.

Which layer lets applications request kernel services?

The system call interface.

Terminal vs shell?

The terminal is the window. The shell is the program inside it that interprets your commands.
